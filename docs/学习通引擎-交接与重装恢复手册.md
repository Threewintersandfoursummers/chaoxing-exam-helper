## 0. 一分钟结论（先看这段）

1. **引擎跑在手机上（Termux + Node），不在电脑上。** 电脑只是"改代码、推文件、看日志"的工具。
2. **重装电脑不会影响手机上的引擎。** 考试当天照样 `bash ~/chaoxing/run.sh` 就能跑。
3. 重装会抹掉电脑上的：本项目全部源码、`tools/platform-tools/adb.exe`、`.workbuddy` 里的对话记忆。
4. **手机里已有全部源码**（含 `config.json` 里的 API Key），所以真正的"备份"在手机上。
5. 重装完成后，按 **§5 五条命令** 就能把整个项目从手机拉回电脑，一分钟恢复开发环境。

## 1. 系统架构（三层）

```
┌─ 手机屏幕（学习通 WebView） ─────────────┐
│   ↑ 读屏：uiautomator dump               │
│   ↓ 点击：input tap / input swipe        │
│   ↓ 填空：ADBKeyboard 广播注入           │
├─ Termux 里的 Node 引擎（真正的大脑）─────┤
│   src/single.mjs 主循环 / src/auto.mjs 答题│
│   通道：adb 连 127.0.0.1:5555（手机连自己）│
├─ DeepSeek API（出答案）──────────────────┤
└──────────────────────────────────────────┘
```

关键点：`127.0.0.1:5555` 是**手机自己连自己**的 loopback，跟 USB 线、Wi-Fi、流量都没关系。

## 5. 重装电脑后：恢复开发环境（五步）

> 前置：手机保持可用、开发者选项里的「USB 调试」已开、数据线能连。

**Step 1 · 装 adb（二选一）**
- 最省事：去 Google 官方下 `platform-tools` 解压，或
- 如果你从备份里保留了本项目 `tools/platform-tools/` 整个文件夹，直接用里面的 `adb.exe`（其余 dll 必须同目录）

**Step 2 · 连手机**
```bash
adb devices          # 认到序列号 <你的设备序列号> 即可
adb -s <你的设备序列号> tcpip 5555     # 让手机 adbd 开无线端口（引擎必需）
```

**Step 3 · 把整个项目从手机拉回来（一条命令，已实测）**
```bash
adb -s <你的设备序列号> exec-out run-as com.termux tar -cf - -C /data/data/com.termux/files/home chaoxing > chaoxing.tar
tar -xf chaoxing.tar        # Windows 自带 tar 即可，解出 chaoxing/ 目录
```
> 注意：`exec-out` 不能换成 `shell`（会被 CRLF 破坏成乱码二进制）。

**Step 4 · 校验版本**
```bash
cd chaoxing && md5sum start.sh src/auto.mjs src/single.mjs src/llm.mjs
```
（应为 §3 里对应值）

**Step 5 · 验证这份副本能跑**
```bash
node --check src/auto.mjs && node --check src/single.mjs
node --test test/auto.test.mjs
```
本机已实测：解包后语法检查通过、`# pass 1 / # fail 0`。

> Windows 上 `node` 如果没装：装 Node 18+ 即可，引擎只用到内置模块，**没有任何 npm 依赖**。

## 6. 日常操作 SOP（考试当天照这个走）

### 启动
1. 打开 Termux，输入：
   ```
   bash ~/chaoxing/run.sh
   ```
2. 看到自检全部 `✓`、最后出现「即将启动」→ 按 **Home**
3. 打开学习通 → 进考试 → **不要碰屏幕**
4. 引擎在你进题目页后自动开始连答

### 停止（只有这两种）
- Termux 里按 `Ctrl+C`
- 另开会话：`touch ~/chaoxing/STOP`

> 引擎**不会**自己退出：答完一套进入待命，你开下一套它自动接着答。

### 换版（改完代码后）
```
touch ~/chaoxing/STOP     # 停旧版
# 等 4 秒，确认进程消失
bash ~/chaoxing/run.sh    # 起新版
```
**答题中途不要换版**（会把当前这题重答一遍，可能把对的改错）。等屏幕上出现待命提示再换。

### 看日志
```
tail -30 ~/run.log                                   # 主日志
ls -t ~/chaoxing/dump/session-*.log | head -1        # 最新会话
tail -20 "$(ls -t ~/chaoxing/dump/session-*.log | head -1)"
```

### 从电脑推文件（开发时）
```bash
export MSYS_NO_PATHCONV=1        # Git Bash 必加，否则 /data/... 会被改写成 Windows 路径
adb -s <你的设备序列号> push src/auto.mjs /data/local/tmp/p_auto.mjs
adb -s <你的设备序列号> shell "run-as com.termux sh -c 'cp /data/local/tmp/p_auto.mjs /data/data/com.termux/files/home/chaoxing/src/auto.mjs'"
```
推文件不影响正在跑的进程（它用内存里的旧代码），要生效必须换版重启。

## 7. 踩过的坑（血泪清单，别重犯）

### 7.1 termux-api 广播会永久挂起
`termux-toast` / `termux-clipboard-*` 在本机 APK 缺 `TermuxApiReceiver`，调用后**永不返回**（`timeout 8` 都拦不住，RC=124）。`|| true` 只防非零退出，**防不了挂起**。所以 `start.sh` 里一行 termux-api 都不能有——曾经就是它让引擎启动后进程无声消失。

### 7.2 Git Bash 会吃掉 `run-as` 的引号
`adb shell run-as com.termux sh -c '...'` 里的单引号会被本地 bash 剥掉，远端命令被拆散，后半截以 shell(uid 2000) 执行，报「cd 拒绝」。正确写法：**外层双引号、内层单引号**，并加 `MSYS_NO_PATHCONV=1`。

### 7.3 adb 会自动把手机注册成 `emulator-XXXX`
手机开 5555 后，本机 adb 扫端口会把它当模拟器注册（见过 `emulator-5554` / `emulator-5556`），于是出现「more than one device」或 `-s 127.0.0.1:5555` 查无此设备。
**解法：所有电脑端命令都带 `-s <你的设备序列号>`**；`start.sh` 里已加兜底（扫设备表所有本地序列号，哪个能跑 shell 用哪个）。

### 7.4 USB 插拔会重置 adbd
- 插回 USB → adbd 回 USB 模式 → **5555 监听消失**，引擎立刻起不来
- 拔线瞬间底层命令集体失败 → 曾有未捕获异常让 Node 无声自杀
**铁律：电脑上最后一条命令永远是 `adb tcpip 5555`，然后拔线不回头。插回 USB 后必须重发 tcpip。**
（引擎侧已加"不死金身"：未捕获异常全吞、断线自动重连、连续失败降级 rish。）

### 7.5 `adb tcpip 5555` 后有 10~20 秒抖动
刚发完 tcpip 立刻启动引擎，自检会误报「adb 和 rish 都不通」。**等 10 秒重跑即可**，不用改任何东西。

### 7.6 `pkill -f "bash start.sh"` 会杀掉自己
`-f` 匹配命令行，自己的 adb shell 会话也被匹配（exit 143）。用正则绕开：`pkill -f "start[.]sh"`。

### 7.7 WebView 无障碍树会"变瞎"（最阴的坑）
连续答十几题后，节点树会从 58 节点/17 段文字掉到 26 节点/2 段文字，肉眼有按钮但树里没有。两种表现：
- **翻页卡死**：看不到「下一题」→ 已修：空白区轻点唤醒 + 固定坐标兜底点击（仅在整树无「交卷」字样时才敢盲点）
- **填空被跳过**：找不到 `EditText` → 已修：重抓 2 次 → 题干顶部轻点唤醒再抓 → 整屏仅一个输入框时直接认定

### 7.8 vivo 会杀 Termux 后台
需要在系统设置里：电池 → 后台耗电管理 → Termux 设为「允许后台高耗电」；并关掉「省电模式」。熄屏超时已设为 30 分钟。

### 7.9 交卷必须人工点
引擎看到「提交/交卷」只停手不点（防误触）。最后一下永远由人来。

## 10. 万一手机也重装了（最坏情况）

1. 装 Termux（F-Droid 版）、学习通、ADBKeyboard（`ADBKeyboard.apk`，本机 `chaoxing_app/apk/` 有存档）
2. Termux 里：`pkg update && pkg install nodejs android-tools`
3. 打开手机的「无线调试」或用 USB 先 `adb tcpip 5555`，Termux 里 `adb connect 127.0.0.1:5555` 并允许授权
4. 把 `chaoxing/` 整个目录（含 `config.json`）拷回 `~/chaoxing`
5. `bash ~/chaoxing/run.sh`，自检应全绿
